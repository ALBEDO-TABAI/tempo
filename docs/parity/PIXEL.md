# Pixel / layout parity

Generated by `packages/parity/pixel.mjs` against the reference captures (kept outside the repo).
The reference half of every side-by-side is redacted (account, calendar list, other people's / real event titles).

- **pixel**: share of pixels matching within pixelmatch threshold 0.1 at 2×. Text is rasterised with different fonts (macOS system font vs. Linux fallbacks), so this is a lower bound.
- **layout**: share of 8×8 css-px blocks whose mean colour is within 10/255 — geometry + colour, independent of glyph shapes.
